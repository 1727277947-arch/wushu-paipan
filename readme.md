# 传统文化娱乐 · 五术排盘

一个纯前端的中华传统术数与民俗排盘应用，收录五种术数排盘，外加一组解梦。
无需构建、无需依赖、无需联网，双击即用。

## 七种功能

| 功能 | 定位 | 说明 |
| --- | --- | --- |
| **命理解读** | 论命 · 走向 | 把八字翻译成对人生走向的论断：什么命、财禄官运、能否转运、何时转运 |
| **八字** | 算「命」 | 最传统、最主流、最普及 |
| **六爻** | 算「事」 | 最正统的卜卦 |
| **大六壬** | 卜筮巅峰 | 术数界公认的巅峰，门槛高、会的人少 |
| **紫微斗数** | 算「命」 | 体系精密，偏台湾、香港流行 |
| **奇门遁甲** | 择时布局 | 地位高，主要用于择时、布局 |
| **解梦** | 梦象 · 吉凶 | 依《周公解梦》象义与五行归类，拆解梦中之「象」，断吉凶、给建议 |

## 运行方式

### 一、桌面应用（推荐）

双击桌面的 **五术排盘** 快捷方式，或直接运行：

```
dist\五术排盘\五术排盘.exe
```

.exe 已把页面与 Python 运行时一起打包，**不装 Python、不联网、不需浏览器**，双击即开。
窗口标题为「五术排盘 · 传统文化娱乐」。

想重新打包，双击 `构建打包.bat` 即可（需先装 `python -m pip install pywebview pyinstaller`）。

### 二、源码方式

页面本身是纯前端，但用了 ES 模块，**用 `file://` 直接打开会被浏览器拦掉模块加载**，
所以要用本地服务器：

```bash
python app.py          # 起桌面窗口（需 pip install pywebview）
python -m http.server 8080   # 或只用浏览器
```

也可以双击 `index.html` 快速看个大概，但标签页与表单不会正常渲染。

## 算法说明

全部推算为**实时天文计算**，不依赖任何预置数据表：

- **节气**：采用 Meeus 太阳视黄经算法迭代求解，与官方历书误差在分钟级。
  例如 2024 年冬至 12-21 17:14、2025 年立春 02-03 22:10，均与紫金山天文台结果一致。
- **农历**：以 Meeus 朔望月周期（含 14 项附加修正）推算朔日，按「无中气置闰」定闰月。
  经 1990–2035 年共 16436 天连续校验，无跳日、无重复、月长均为 29 或 30 天。
- **日柱**：以 1900-01-01 为甲戌日锚点，六十甲子循环推算。
- **大六壬三传**：依次按贼克、比用、涉害、遥克、昴星取法，并处理伏吟、反吟特例。
- **奇门定局**：按二十四节气 × 上中下元共 72 局表，经全表校验全部正确。
- **解梦**：梦境文本按「长词优先」匹配梦象库（现有 68 个梦象、约 200 个关键词），
  每个梦象归五行、带吉凶倾向；吉凶分取梦象倾向的均值再叠加梦中情绪权重，避免梦象多则分数虚高。
  另依做梦时辰定「梦应」方向。

## 命理解读的论断内容

「命理解读」标签页会依八字给出七段完整论断：

1. **命局总论** —— 日主强弱、全局气场、此命的底色
2. **格局与命性** —— 区分「先天禀赋」（命中最强之神）与「后天所宜」（用神），定出是**财命、官命、印命、食伤命或禄命**
3. **财富与禄命** —— 财星力量、能否担财、是财命还是禄命、财富指数
4. **官运与名位** —— 官杀与印星力量、有无官运、是否「官杀攻身」或「伤官见官」
5. **一生行运走势** —— 十步大运逐步吉凶，指出一生最得力的阶段与滞涩期
6. **能否转运 · 何时转运** —— 当前所处大运的吉凶、最近的转运节点年份、未来十年最吉与最凶的流年
7. **分项指数** —— 财富、官运、事业、婚姻、健康、晚运六项百分制评分

同时以图形呈现：命型结论卡、六项指数条、十神力量分布、大运时间轴、未来十年流年吉凶网格。

**吉凶判定方法**：以用神喜忌为基准，天干权重 0.8、地支权重 1.0，藏干按本气/中气/余气 0.3/0.15/0.08 加权，合成每一步大运与每一个流年的吉凶分，再依阈值定为 大吉 / 吉 / 平 / 不佳 / 凶 五档。

**行文语气**：七段论断一律用大白话，第二人称「你」，不堆术语。
十神在句中出现时统一用短标签并加口语注脚：
比劫＝**自己人**（兄弟、朋友、合伙人）、食伤＝**才华**（手艺、创意、表达）、
财＝**钱财**（挣钱的路子、管事的本事）、官杀＝**名位**（名分、职位、约束、责任）、
印＝**学问**（知识、名声、贵人、长辈）。
术语首次出现即给一句人话解释，例如「财多身弱」会写成「机会一大把，可你接不住」。
措辞上直给结论 —— 有官运就说有，没有就说「这条路你走起来会别扭」，不绕弯子。

## 解梦的论断内容

「解梦」标签页把梦讲一遍，即给出四段白话论断：

1. **总断** —— 从梦里挑出哪些「象」，此梦整体属 大吉 / 吉 / 平 / 不佳 / 凶，以及此梦的应期方向
2. **逐象详解** —— 每一样梦象单独断，附「宜」的建议
3. **梦境五行气象** —— 梦象按五行归类，指出此梦的气落在哪一行，翻译成该往哪个方向使劲
4. **该怎么做** —— 把建议汇成可照做的几条，并叮嘱该忌讳什么

同时以图形呈现：结论卡（吉凶、最重的五行、应期时辰、吉凶分）、梦象卡片、五行分布条、时辰梦应。

**五行归类**：木主生发、火主明亮、土主稳固、金主决断、水主流通。
**情绪权重**：喜悦 +1.2、害怕 −1.2、悲伤 −1.0、愤怒 −0.8、平静 0，
叠加到梦象均分上（乘 0.35），再按 1.5 / 0.6 / −0.6 / −1.5 的阈值分五档。
**梦应**：依传统「十二时辰梦应」说法，按做梦时辰给出应事的方位与迟速。

梦象库现收录 68 个常见梦象、约 200 个触发关键词，覆盖天象、山水、人物、动物、器物、情境六类。
